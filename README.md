# Terra-W2--turtle-attempt-

Description:
Don't you love Halloween? Come over here and get a little nostalgic! I'll even toss in a cool-looking dark-mode skin for the terminal of the text-based, interactive story game. (Sorry, sorry. I know that this game was shipped one day shy of THE day... but Halloween can live on, no? So come on and try it out!) The prompts are straightforward for convenience. They were designed to be self-explanatory. This is a WIP, so we so far only have aesthetic characters for the visual pleasure/elements. Enjoy!!

Update: (10/29/26)  --> transferred this GitHub repository into a newly-made Hackclub codespace!
Update: (10/31/26)  --> This project is now centered around Halloween. It is an interactive story-game; text-based!

How to play: 
1) Run the code (should be an executable file!)
2) Follow the in-game prompts, and type what the game asks of you. Make sure to press enter!!
3) Play to the end, and have fun!!


You can...
- name your character
Pick a name, any name
- pick one of three costumes:
Be a bear, a duck, or a mage!
- choose dark or light mode
I recommend dark mode :)
- sneak out to go trick-or-treating, despite being grounded on Halloween!
The candy makes it worth it
- see a cool layout/blueprint/map of your family house
Or don't. All up to you, of course.
- get candy, yummmm!
And pay food tax to your Dad, else Mom will be on you for sneaking out while grounded.
